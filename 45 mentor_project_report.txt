
# Project Report: Neuro Assistant for Machine Learning

## Overview
This project aims to create an AI-powered assistant to help users learn machine learning theory and practice.
The assistant is implemented as a Telegram bot and supports practical tasks via Google Colab, with progress stored in JSON.

## Key Discussions and Decisions

1. **Initial Plan**:
   - Use a relational database to store user data and progress.
   - Integrate adaptive learning and gamification to engage users.

2. **Switch to JSON**:
   - Decided to use JSON for data storage to simplify the implementation and deployment.
   - JSON is portable, easy to debug, and sufficient for a small-scale project.

3. **Features Implemented**:
   - **User Registration**: Users can register and create profiles.
   - **Progress Tracking**: Tracks completed lectures and quizzes.
   - **Adaptive Learning**: Adjusts content based on user progress.
   - **Gamification**: Awards achievements and tracks user levels.

## Tasks Completed

### 1. Telegram Bot
- **Commands**:
  - `/start`: Starts interaction and provides instructions.
  - `/register`: Registers the user and initializes their profile.
  - `/menu`: Displays available options.
  - `/lecture`: Simulates completing a lecture.
  - `/quiz`: Simulates completing a quiz.
  - `/progress`: Displays user progress, level, and achievements.

### 2. JSON-Based Storage
- Data Structure:
  - `users`: List of registered users with details (name, level, points).
  - `progress`: Dictionary of user progress (lectures, quizzes).
  - `achievements`: Dictionary of user achievements.
