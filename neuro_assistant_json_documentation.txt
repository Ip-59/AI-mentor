
# Neuro Assistant: Using JSON for Data Storage

This project uses JSON files to store user data, progress, and achievements. This approach simplifies implementation and
removes the need for database management, making the project more lightweight.

## JSON Structure

### Root Keys
- **users**: A list of all registered users. Each user is represented by a dictionary.
- **progress**: A dictionary where the keys are usernames, and the values are dictionaries tracking user progress.
- **achievements**: A dictionary where the keys are usernames, and the values are lists of achievements earned.

### Example User Data
```json
{
    "username": "example_user",
    "name": "Example Name",
    "registration_date": "2024-01-01T12:00:00Z",
    "level": 1,
    "total_points": 0
}
```

### Example Progress Data
```json
"progress": {
    "example_user": {
        "lectures_completed": [],
        "quizzes_completed": []
    }
}
```

### Example Achievements Data
```json
"achievements": {
    "example_user": []
}
```

## Benefits of JSON
- Simplifies data storage and retrieval without requiring database setup.
- Human-readable and easy to debug.
- Portable across systems.

## Limitations
- Not suited for handling large-scale data or concurrent access by multiple users.
- Requires careful handling to avoid overwriting data during simultaneous writes.

## Usage Notes
- JSON files are updated after each significant change to user data.
- Ensure proper error handling when reading and writing to the file.
