
# Отчет о работе над проектом: Нейро-Помощник для обучения машинному обучению

## Общая информация о проекте
Цель проекта — разработка интеллектуального помощника, который обучает пользователей основам машинного обучения через теоретические материалы и практические задания. 
Помощник реализован в формате Telegram-бота с поддержкой практических заданий на Google Colab. Прогресс пользователей сохраняется в JSON-файле.

---

## Обсуждения и принятые решения

### Первоначальный план:
1. Хранение данных пользователей и прогресса в базе данных.
2. Реализация адаптивного обучения и геймификации для повышения вовлеченности.
3. Использование Google Colab для выполнения практических заданий.
4. Интеграция Telegram-бота с базой данных и Colab.

### Важное изменение:
- В процессе обсуждения было принято решение **заменить базу данных на JSON** для хранения данных. 
Это было сделано для упрощения разработки и развертывания проекта. JSON легко читается, не требует сложной настройки и идеально подходит для небольшого количества пользователей.

---

## Выполненные задачи

### 1. Telegram-бот
**Функциональность:**
- **Команды:**
  - `/start` — начало взаимодействия, инструкции для пользователя.
  - `/register` — регистрация нового пользователя.
  - `/menu` — отображение доступных функций.
  - `/lecture` — выполнение лекции.
  - `/quiz` — выполнение теста.
  - `/progress` — просмотр прогресса пользователя.

**Особенности:**
- Прогресс, уровень и достижения каждого пользователя сохраняются в JSON.
- Реализована система наград и уровней для геймификации:
  - **Достижения:** "First Lecture", "Quiz Master", "ML Enthusiast".
  - **Уровни:** Каждый 100 очков переводят пользователя на следующий уровень.

**Файлы:**
- [Скрипт Telegram-бота](sandbox:/mnt/data/neuro_assistant_bot_gamification.py)
