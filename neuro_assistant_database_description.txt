
# Description of Neuro Assistant Database Structure

This document describes the structure of the database used in the Neuro Assistant project.

## Tables

### 1. Table `Users`
- **Purpose**: Stores information about users.
- **Columns**:
  - `user_id`: Unique identifier for each user.
  - `telegram_username`: Unique Telegram username of the user.
  - `name`: Name of the user.
  - `registration_date`: Date of registration, default is the current timestamp.

### 2. Table `Progress`
- **Purpose**: Tracks user's progress in each module.
- **Columns**:
  - `progress_id`: Unique identifier for each progress entry.
  - `user_id`: Reference to `Users` table.
  - `module_name`: Name of the module.
  - `status`: Status of module completion (default is 'incomplete').
  - `completion_date`: Date when the module was completed.

### 3. Table `QuizResults`
- **Purpose**: Stores results of quizzes taken by users.
- **Columns**:
  - `result_id`: Unique identifier for each quiz result entry.
  - `user_id`: Reference to `Users` table.
  - `quiz_id`: Identifier of the quiz.
  - `score`: User's score in the quiz (0-100).
  - `attempt_date`: Date of quiz attempt, default is the current timestamp.

### 4. Table `LectureProgress`
- **Purpose**: Tracks user's progress in lectures.
- **Columns**:
  - `progress_id`: Unique identifier for each lecture progress entry.
  - `user_id`: Reference to `Users` table.
  - `lecture_id`: Identifier of the lecture.
  - `completed`: Flag indicating whether the lecture is completed (default is FALSE).
  - `completion_date`: Date when the lecture was completed.
