### Как это работает:

1. **OpenAI API**:
   - Мы используем модель `gpt-3.5-turbo` для генерации заданий.
   - Промпт (запрос) формируется так, чтобы AI понимал, что нужно создать задание по машинному обучению.

2. **Генерация задания**:
   - AI генерирует текст, который содержит задание, подсказку, функцию проверки и сообщения об ошибке/успехе.
   - Мы парсим этот текст в словарь Python с помощью `eval`.

3. **Контекст**:
   - Если передан контекст (например, предыдущие задания), он учитывается при генерации нового задания.

4. **Пример задания**:
   - AI может сгенерировать задание, например:
     ```python
     {
         'problem': 'Создайте модель логистической регрессии для классификации данных.',
         'hint': 'Используйте LogisticRegression из sklearn.linear_model.',
         'check': lambda ns: 'LogisticRegression' in ns and callable(ns['LogisticRegression']),
         'error': 'Нужно создать модель логистической регрессии.',
         'success': 'Отлично! Модель логистической регрессии создана!'
     }
     ```

### Что нужно для запуска:

1. **Установка зависимостей**:
   - Убедитесь, что установлены библиотеки `openai` и `python-dotenv`:
     ```bash
     pip install openai python-dotenv
     ```

2. **API ключ OpenAI**:
   - Создайте файл `.env` в корне проекта и добавьте туда ваш API ключ:
     ```
     OPENAI_API_KEY=ваш_ключ
     ```

3. **Интеграция с Learnly**:
   - В `engine.py` можно заменить статические задания на генерацию через `generate_ml_task()`.

---

### Пример интеграции с `engine.py`:

```python
from ai import generate_ml_task

class LearnlyEngine:
    def __init__(self):
        self.current_task = 1
        self.tasks = {}  # Задания будут генерироваться динамически

    def get_next_task(self):
        """Генерирует следующее задание с помощью AI."""
        task = generate_ml_task(context=f"Предыдущее задание: {self.current_task - 1}")
        if task:
            self.tasks[self.current_task] = task
            return task
        else:
            return None
```
