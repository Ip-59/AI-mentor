на холсте оригинальный engine.py, его надо доработать с учетом моих требований:
В процессе обучения по курсу AI/ML необходимо держать в памяти программы, записывать в файл lesson.json, считывать при новом запуске программы AI-учителя по курсу следующую информацию: 
1. имя студента;
2. количество времени выделенное для обучения по курсу;
3. уровень сложности, выбранный студентом;
4. дата и время начала обучения;
5. общая средняя оценка студента по пройденным шагам;
6. перечень шагов по программе обучения, полученной из  запроса к OpenAI на генерацию подробной программы по курсу AI/ML с одним уровнем детализации (перечень всех шагов по программе обучения), учитывающей заданное количество часов на изучение курса (например, на 100-120 часов), обеспечивающей полное понимание концепций и получение навыков, необходимых для успешного прохождения курса. При этом ограничение времени на изучение курса в (количество часов), уровень студента и краткое описание его знаний на начало курса должны быть изменяемыми параметрами в запросе к OpenAI. Для лучшего проектирования структуры файла JSON создай такую подробную программу обучения по курсу AI/ML. Степень детализации программы обучения по курсу всего один, то есть это будет простой последовательный перечень подтем (шагов, элементов курса), которые надо будет последовательно изучить. Для примера уровень студента - начинающий, умеет пользоваться компьютером, имеет начальные базовые знания по программированию на Python. Желательно, чтобы каждая минимальная часть курса занимала не боле 1 - 2 экранов (страниц на экране компьютера) и была логически завершенной. После каждой части для контроля освоения учебного материала предполагается задавать студенту контрольные вопросы, тесты, очень небольшие контрольные задания, например, по написанию кода.
7. содержание лекции (урока) для каждого шага, которое будет по мере обучения и движения от шага к шагу генерироваться с помощью отдельного запроса к OpenAI.
8. оценка, полученная студентом по каждому шагу обучения;
9. по каждому шагу обучения - время старта;
10. по каждому шагу обучения - время окончания.

Спроектируй такой файл JSON, создай пример файла.

в файле engine.py надо исправить и/или написать (возможно, переписать заново)  код на Python для: 
1. проверки наличия такого файла JSON;
2. создания такого файла JSON, если он ещё не существует. Cозданный файл должен в себе содержать все шаги программы обучения по курсу AI/ML. Возможно код Python для запроса к OpenAI c заданием на генерацию описанной выше подробной программы курса должен быть внутри кода для создания файла JSON;
3. чтения этого файла JSON;
4. дополнения этого файла JSON записями, по мере прохождения курса обучения;

Напиши код Python для запроса к OpenAI в программе c заданием на генерацию описанной выше подробной программы курса.

Если файл lesson.json не найден, значит он должен быть создан. Начальные данные внести любые для примера, для отладки проекта.

В файле lesson.json необходимо обеспечить запись о текущем шаге курса (это следующий после законченного). Законченным шагом считать тот, по которому есть оценка.

Надо написать код для движения по шагам программы обучения.

В файле engine.py надо пометить комментариями строки:
1. измененные тобой комментарием "исправлено ChatGPT"
2. добавленные тобой "добавлено ChatGPT"м
