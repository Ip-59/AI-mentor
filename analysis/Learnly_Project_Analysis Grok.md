### Анализ проекта в каталоге `learnly` репозитория [github.com/Ip-59/AI-mentor](https://github.com/Ip-59/AI-mentor)

Проект в подкаталоге `learnly` представляет собой систему AI-учителя по машинному обучению, предназначенную для обучения студентов через интерактивные уроки, задания и отслеживание их прогресса. Ниже представлен подробный анализ проекта, включая описание его структуры, работы каждого модуля, функций, структур данных, а также выявленные ошибки с предложениями по их исправлению. Файлы, начинающиеся с "old", в соответствии с запросом, не рассматриваются.

---

## 1. Общее описание проекта
Проект реализован в подкаталоге `learnly` репозитория [github.com/Ip-59/AI-mentor](https://github.com/Ip-59/AI-mentor). Основной файл — Jupyter Notebook `learnly.ipynb`, который служит точкой входа. Вспомогательная логика содержится в модулях `engine.py` и `lesson.py`. Система собирает данные о студенте, предоставляет уроки с лекциями и заданиями, оценивает ответы и сохраняет прогресс.

---

## 2. Структура файлов и их назначение
- **`learnly.ipynb`**: Основной файл, запускающий процесс обучения. Собирает данные о студенте и инициирует урок.
- **`engine.py`**: Содержит класс `LearnlyEngine`, управляющий циклом урока и взаимодействием со студентом.
- **`lesson.py`**: Содержит класс `Lesson`, который отвечает за структуру урока и управление его частями.
- **`student_data.json` (или `<email>_data.json`)**: Файл для хранения данных студента (прогресс, оценки).
- **`lesson.json`**: Хранит структуру урока (лекции, задания).
- **`lesson_protocol.json` (или `<email>_protocol.json`)**: Логирует взаимодействия студента с системой.

## 3. Подробное описание модулей, функций и структур данных

### 3.1 Модуль `lesson.py`
Модуль управляет структурой урока и его частями.

#### Класс `Lesson`
- **`__init__(self, lesson_file='lesson.json')`**  
  Инициализирует объект урока. Принимает путь к файлу `lesson.json`, загружает его или создаёт новый, если файла нет.  
  - **Аргументы**: `lesson_file` — путь к JSON-файлу урока (по умолчанию `lesson.json`).  
  - **Атрибуты**:  
    - `self.lesson_file`: Путь к файлу урока.  
    - `self.parts`: Список словарей, где каждый словарь — часть урока с полями `part_number`, `topic`, `type` (например, `lecture`, `multiple_choice`, `code_task`), `content` и др.  
    - `self.last_two_parts`: Список последних двух частей урока для контекста (берётся как `self.parts[-2:]`, если частей ≥ 2, иначе `self.parts[:]`).  

- **`load_lesson(self)`**  
  Загружает содержимое урока из `lesson.json`. Если файл отсутствует, создаёт его с начальными частями (например, "Введение в ML").  
  - **Логика**: Читает JSON-файл, присваивает `self.parts` загруженные данные. При отсутствии файла инициализирует `self.parts` базовым уроком и записывает его в файл.  

- **`add_part(self, new_part)`**  
  Добавляет новую часть урока в `self.parts` и обновляет `lesson.json`.  
  - **Аргументы**: `new_part` — словарь с данными новой части (например, `{'part_number': 3, 'topic': 'Линейная регрессия', 'type': 'lecture', 'content': '...'}`).  
  - **Логика**: Добавляет `new_part` в `self.parts`, обновляет `self.last_two_parts` и перезаписывает файл.  

- **`get_part(self, index)`**  
  Возвращает часть урока по индексу.  
  - **Аргументы**: `index` — номер части.  
  - **Возвращает**: Словарь с данными части или `None`, если индекс вне диапазона.  

#### Структуры данных
- **`self.parts`**: Список словарей, представляющих части урока. Пример:  
  ```json
  [
    {"part_number": 1, "topic": "Введение в ML", "type": "lecture", "content": "ML — это..."},
    {"part_number": 2, "topic": "Введение в ML", "type": "multiple_choice", "content": "Что такое ML? a) ... b) ...", "correct_answer": "a"}
  ]
  ```
- **`self.last_two_parts`**: Список последних двух элементов из `self.parts` для контекста.

### 3.2 Модуль `engine.py`
Модуль управляет процессом урока и взаимодействием со студентом.

#### Класс `LearnlyEngine`
- **`__init__(self, student_data, lesson, protocol_file='lesson_protocol.json')`**  
  Инициализирует движок урока.  
  - **Аргументы**:  
    - `student_data`: Словарь с данными студента (имя, e-mail, прогресс).  
    - `lesson`: Объект класса `Lesson`.  
    - `protocol_file`: Путь к файлу протокола (по умолчанию `lesson_protocol.json`).  
  - **Атрибуты**:  
    - `self.student_data`: Данные студента.  
    - `self.lesson`: Объект урока.  
    - `self.protocol_file`: Путь к файлу протокола.  
    - `self.current_part_index`: Текущий индекс части урока (начинается с 0).  

- **`start_lesson_loop(self)`**  
  Запускает цикл урока, перебирая части и обрабатывая ввод студента.  
  - **Логика**:  
    1. Для каждой части урока из `self.lesson.parts`:  
       - Выводит содержимое части (`part['content']`).  
       - Ждёт ввода студента (ответ или команда: "дальше", "расскажи подробнее", "приведи пример кода", "закончи урок").  
    2. Обрабатывает ввод:  
       - "дальше": Переходит к следующей части, обновляет данные студента.  
       - "расскажи подробнее": Выводит дополнительную информацию (если есть).  
       - "приведи пример кода": Показывает код, если часть — `code_task`.  
       - "закончи урок": Завершает цикл.  
       - Ответ на задание: Оценивает его через `evaluate_answer`, обновляет данные и переходит дальше.  
    3. Логирует взаимодействие через `log_interaction`.  

- **`log_interaction(self, role, message_type, content)`**  
  Записывает взаимодействие в файл протокола.  
  - **Аргументы**:  
    - `role`: Роль (например, "student" или "system").  
    - `message_type`: Тип сообщения (например, "input", "output").  
    - `content`: Содержимое взаимодействия.  
  - **Логика**: Добавляет запись в JSON-файл с временной меткой.  

- **`update_student_data(self, part, time_spent, answer=None, grade=None)`**  
  Обновляет данные студента после прохождения части.  
  - **Аргументы**:  
    - `part`: Словарь с данными части урока.  
    - `time_spent`: Время, затраченное на часть (в секундах).  
    - `answer`: Ответ студента (если есть).  
    - `grade`: Оценка за ответ (если есть).  
  - **Логика**: Обновляет `self.student_data`, добавляя время и, если применимо, ответ и оценку в раздел `topics_studied`. Пересчитывает общий рейтинг.  

- **`evaluate_answer(self, part, answer)`**  
  Оценивает ответ студента.  
  - **Аргументы**:  
    - `part`: Часть урока (словарь).  
    - `answer`: Ответ студента.  
  - **Возвращает**: Оценку (например, 5 для правильного ответа в `multiple_choice`, иначе упрощённая логика).  

#### Структуры данных
- **`self.student_data`**: Словарь с данными студента. Пример:  
  ```json
  {
    "name": "Иван",
    "email": "ivan@example.com",
    "hours_to_study": 10,
    "difficulty": "beginner",
    "topics_studied": [
      {"topic_name": "Введение в ML", "blocks": [{"part_number": 1, "time_spent": 300, "grade": 5}]}
    ],
    "overall_rating": 5
  }
  ```
- **`self.lesson`**: Объект `Lesson`.  
- **`self.protocol_file`**: Путь к файлу протокола. Пример записи:  
  ```json
  [
    {"timestamp": "2023-10-01 12:00", "role": "student", "message_type": "input", "content": "дальше"}
  ]
  ```

### 3.3 Файл `learnly.ipynb`
- **Функциональность**:  
  1. Запрашивает данные о студенте через `input` (имя, e-mail, часы на обучение, уровень сложности, типы заданий).  
  2. Сохраняет данные в `student_data.json` или `<email>_data.json`.  
  3. Создаёт объект `Lesson` и загружает/создаёт урок.  
  4. Создаёт объект `LearnlyEngine` и запускает `start_lesson_loop`.  

---

## 4. Как работает проект
1. **Сбор данных о студенте**:  
   В `learnly.ipynb` пользователь вводит данные (имя, e-mail и т.д.), которые сохраняются в JSON-файл.  
2. **Загрузка или создание урока**:  
   Класс `Lesson` загружает `lesson.json` или создаёт его с начальными частями (например, "Введение в ML").  
3. **Цикл урока**:  
   - `LearnlyEngine.start_lesson_loop` выводит каждую часть урока.  
   - Студент взаимодействует с системой через команды или ответы.  
   - Система обновляет данные студента и логирует действия.  
4. **Завершение**:  
   Урок заканчивается по команде "закончи урок" или при прохождении всех частей.

## 5. Выявленные ошибки и предложения по исправлению
1. **Отсутствие обработки ошибок при работе с файлами**:  
   - **Проблема**: Методы вроде `load_lesson` и `log_interaction` не обрабатывают исключения (например, `IOError`).  
   - **Исправление**: Добавить блоки `try-except`:  
     ```python
     try:
         with open(self.lesson_file, 'r') as f:
             self.parts = json.load(f)
     except IOError:
         self.parts = []
         self.save_lesson()
     ```

2. **Упрощённая оценка ответов**:  
   - **Проблема**: `evaluate_answer` даёт 5 баллов для всех типов заданий, что не подходит для `open_question` или `code_task`.  
   - **Исправление**: Реализовать сложную логику: для `open_question` — анализ ключевых слов, для `code_task` — запуск кода.  

3. **Отсутствие валидации ввода студента**:  
   - **Проблема**: Нет проверки корректности ввода (например, для `multiple_choice`).  
   - **Исправление**: Добавить валидацию:  
     ```python
     if part['type'] == 'multiple_choice' and answer not in ['a', 'b', 'c', 'd']:
         print("Некорректный ответ. Выберите a, b, c или d.")
         return None
     ```

4. **Неправильное завершение урока**:  
   - **Проблема**: При "закончи урок" данные о текущей части не сохраняются.  
   - **Исправление**: Обновлять данные перед выходом:  
     ```python
     if user_input == "закончи урок":
         self.update_student_data(part, time_spent)
         break
     ```

5. **Отсутствие генерации новых частей**:  
   - **Проблема**: Нет метода для создания новых частей урока на основе `last_two_parts`.  
   - **Исправление**: Добавить метод в `Lesson`:  
     ```python
     def generate_part(self):
         new_part = {"part_number": len(self.parts) + 1, "topic": self.last_two_parts[-1]["topic"], "type": "lecture", "content": "Следующая тема..."}
         self.add_part(new_part)
     ```
