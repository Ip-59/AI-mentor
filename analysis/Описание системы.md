## Базовая программа обучения

Существует базовая программа обучения (скажем, в виде файла .md) - набор тем, которые должны быть изучены в рамках курса.

При прохождении очередной темы система подстраивается под предпочтения и уровень подготовки студента, отвечает на его вопросы, предлагает задачи, контролирует выполнение заданий. По окончании темы предполагается, что студент освоил ее на некотором достаточном уровне, и можно двигаться дальше.


## Что сохраняем между сессиями общения

- `preferences`
   - Строка, описывающая предпочтения студента
   - Используется для персонализации взаимодействия с ChatGPT
   - Может содержать любые предпочтения: форма обращения, уровень детализации объяснений, предпочитаемые форматы обучения и т.д.

- `program_id`
   - Строка - уникальный идентификатор программы обучения
   - Позволяет определить, по какой программе идёт обучение
   - Примеры: "ai_ml_course_2024", "python_basics_2024"

- `progress`
   - Текстовое описание прогресса обучения
   - Содержит любую информацию о прогрессе в свободной форме
   - Может включать: пройденные темы, оценки, выполненные задания, текущие цели
   - Позволяет ChatGPT анализировать прогресс и предлагать следующие шаги


## Процесс обучения

 Обучение происходит в форме диалога, где система активно взаимодействует со студентом.

1. **Начало**:
   - Приветствие и краткое введение в тему

2. **Основной процесс**:
   - Система объясняет материал небольшими блоками. Блок - условная структурная смысловая единица урока, которая может содержать теоретический материал, практическое задание, их комбинацию, вопросы студента, уточнения, и т.д. Блок состоит из ячеек Jupyter - реплик
   - В процессе работы
     - Студент может задать вопросы, попросить уточнить, обсудить детали
     - Система отвечает и следует пожеланиям студента
     - Система естественно в диалоге убеждается, что студент понял материал
   - Когда студент усваивает материал, система предлагает следующий блок. Это задача системы - убедиться, что материал понят и студент готов к следующему блоку.

3. **Завершение**:
   - Подведение итогов сессии для студента, в диалоге
   - Сохранение прогресса


## Как создается следующая реплика

- **Типы реплик**
     - `text` - теоретический материал
     - `example` - пример кода
     - `assignment` - практическое задание
     - `question` - вопрос студента
     - `clarification` - уточнение системы
     - `summary` - саммаризированный материал

- **Контекст**:
   - Текущий блок во всех подробностях
   - Уже пройденная часть темы (можно саммаризировать)
   - Прогресс студента, ориентируясь на базовую программу обучения

- **Генерация новой реплики**:
   - Система создает промпт для GPT с требованиями:
     - Новая реплика должна быть связана с предыдущими
     - Должна опираться на уже полученные знания
     - Не должна повторять пройденный материал
   - Передает текущий контекст в промпт

- **Сохранение**:
   - Новая реплика добавляется в структуру урока
   - Обновляется прогресс
   - Сохраняется в файл для следующей сессии

Система адаптирует сложность и тип следующей реплики на основе:
- Уровня подготовки студента
- Успешности выполнения предыдущих заданий
- Количества вопросов и уточнений по текущему материалу
- Базовой программы обучения
