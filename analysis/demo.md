### Многомерная линейная регрессия

**Система** (тип: text):
Многомерная линейная регрессия расширяет концепцию простой линейной регрессии на случай с несколькими признаками. Формула выглядит так:

y = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ + ε

где:
- y - зависимая переменная (целевая)
- x₁, x₂, ..., xₙ - независимые переменные (признаки)
- β₀, β₁, ..., βₙ - коэффициенты модели
- ε - ошибка модели

**Система** (тип: clarification):
Отличный вопрос! В многомерном случае мы также используем метод наименьших квадратов, но работаем с матрицами. Формула для нахождения коэффициентов:

β = (X^T X)^(-1) X^T y

где:
- X - матрица признаков размера (m × n), где m - количество примеров, n - количество признаков
- y - вектор целевых значений
- X^T - транспонированная матрица X
- (X^T X)^(-1) - обратная матрица к произведению X^T X
